# Lista de Compras 1.0.36+40

- Identificador Android: `com.listadecompras.app`; novo app independente da instalação anterior.
- Categorias personalizadas salvas em SQLite com ícones; categorias incluídas em backup JSON schema 6.
- Nova interface de criação de listas com opções visuais, sugestões rápidas e editor redesenhado.
- Compatibilidade com importação de backups antigos (`meu-supermercado-backup` até schema 5).

**Migração obrigatória:** na versão antiga, abra Configurações > Exportar backup; mantenha o arquivo JSON. Instale a nova versão e use Configurações > Importar backup. Não desinstale o app antigo antes de verificar os dados importados. APK e testes Android completos ainda pendentes.
